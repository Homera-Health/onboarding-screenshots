# Onboarding Screenshots

Public host for slide-by-slide screenshots of generated patient onboarding flows.

Folders are named `{brand-slug}-{onboardingClass-slug}-{instance-number}` to match the artifact repo. Each PNG is named after its page number (e.g. `2.1.png`). URLs are referenced from the `Screenshot` field on `Onboarding Pages (Output)` records in the Homera Platform Airtable base.

Populated by the `homera-onboarding-generator` skill.
